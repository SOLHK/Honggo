# Honggo 1.1.15-R8 — 清屏倍速切集的播放回调保护候选

基于 `e6277a0`（已发布 R7），适配范围仍为红果短剧 7.4.3 / Eggplant 7.4.3.33。沿用 Xcode 27.2、iPhoneOS SDK 27.2 和固定 iOS 27.2 模拟器发布门槛。

## 用户场景与已有证据

复现步骤：竖屏视频进入清屏；长按屏幕以 2 倍速播放一段时间；临近本集结束松开；自动进入下一集后画面卡住。

上传诊断来自 R3，系统为 iOS 27.0.1，宿主构建 7.4.3.33。839 条事件覆盖两个启动会话，没有日志丢弃或容量裁剪。当前会话中，贴片展示替换累计调用 429 次，跳过贴片判断累计 27 次；没有 hook 安装失败记录。导出时在设置页，`maskScenes` 为空。脱敏统计见 [R8 日志分析](reverse/7.4.3.33/r8/log-triage.json)。

**旧日志不含长按开始/结束、实际播放速率、当前剧集或视频帧进度，因此不能把某次贴片回调与卡住一一对应。** R3 也尚无 R5 之后的独立外观模块。本次没有把新外观功能认定为 R3 故障原因。

## 本次修正

旧 `HGSkipPatch` 完全替代宿主 `showPatchAdViewWithContext:seriesId:vId:currentTime:patchAdViewReadyBlock:removeBlock:`，每次调用都立即执行 `ready(nil)`。此前注释将其描述为宿主拒绝广告路径，但现存档案仅证实了方法 ABI，没有该方法与调用方回调的反汇编证据，不能确认所有清屏/切集分支都需要这个回调。

R8 恢复由原始宿主方法管理此流程。`HGForwardPatchPresentation` 只记录结构化诊断，并将原始接收者、选择器、全部参数和两个原始回调直接交给原实现。线程、同步或异步调用时机、宿主选择不调用回调的分支、回调顺序和异常传播都保留。插件不会补发 `ready` 或 `remove`，不会强行 `play`、设定倍速、重建播放器或修改视频层。

独立的 `shouldSkipPatchAdWithContext:` 和其他广告条件过滤保持原样；规则索引 16 保留，旧日志的其他规则编号不变。规则 16 的事件改为 `patch.presentation`，明确标注 `action: forwarded`，不再将透传错误记录为广告已跳过。

原始 IMP 在替换公开前通过精确 ABI 校验并保存，重复安装保留第一次的原始入口，第三方后续 hook 不被覆盖。关闭播放插播过滤后重启，沿用原先的不安装该广告模块入口的行为。

**重要边界：还没有现场证明恢复原实现能解决该手机上的卡住，也未证明该展示函数的每条路径都经过保留的跳过判断。** 真机回归同时需要检查贴片广告是否重新出现；这版优先恢复宿主正常播放回调语义，不宣称新增广告覆盖。

## 播放流程增强诊断

增加四个只观察、完整调用原实现的入口。所有类名、方法和 ABI 均来自现有 7.4.3.33 索引，详见 [方法证据](reverse/7.4.3.33/r8/playback-methods.json)。

| 事件 | 观察范围 |
| --- | --- |
| `playback.clean-mode` | 宿主向贴片服务发送清屏模式变更 |
| `playback.model-updated` | 宿主向贴片服务发送滚动结束后的播放模型更新 |
| `playback.state-updated` | 宿主向暂停广告管理器发送播放状态通知 |
| `playback.finish-gate` | 宿主广告实现返回是否拦截播放结束的原始判断 |

这些事件只在增强诊断开启时写入；记录原始调用的前后顺序、布尔状态和线程信息。没有采集内容 ID、剧名、账号、网址、文本或对象地址，也没有读取未经核对的播放器属性。它们是广告观察者收到的生命周期通知，不等同于真实倍速值、每个视频帧或完整手势跟踪。缺失或 ABI 不同的入口跳过并进入兼容快照，不影响其他模块。

## 回归验证设计

- 贴片回归使用生产安装器，覆盖宿主自行拒绝而不调用回调、同步回调、延迟回调、回调中的嵌套请求、原始参数/回调对象和重复安装。旧版强制 `ready(nil)` 应无法通过这些行为检查。
- 播放诊断回归验证增强诊断开关不改变宿主行为、四类方法的调用与参数保留、原始 BOOL 返回、重入、异常和 ABI 拒绝。
- 保留底栏、设置、诊断、配置、广告、外观以及 Python 工具测试；完整通过后才构建并发布测试 dylib。受控宿主测试不运行真实红果 IPA，不代表真机验收。
- 最终 CI、源码提交与产物摘要以该版本 Actions 和发布附件为准。尚未完成的检查不能使用 R7 的结果代替。

## 安装与复测

1. 移除旧 Honggo/HongguoGlass，只注入 `Honggo-1.1.15-R8.dylib`，重签安装后完全退出重开。
2. 在「我的 → 设置 → Honggo」确认版本后，开启增强诊断。
3. 按原来的四步测试，分别在本集结束前松开、跨集后松开；同时检查非清屏时的长按、普通自动下一集和手动上下滑切集。
4. 如仍卡住，在卡住画面截屏以保留现场，然后回设置导出日志，期间不要退出应用。反馈是否仍有声音、进度是否变化、手动暂停再播放能否恢复，并检查贴片广告是否出现。

本版不要求关闭清屏或长按功能；它们仍由宿主处理。原始用户诊断不提交到仓库。
