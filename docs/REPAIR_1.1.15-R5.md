# Honggo 1.1.15-R5：外观定制测试版

## 使用入口

在「我的 → 设置 → Honggo」左上角点击「外观」。首次选择「应用『玻璃外观』预设」，确认后完全退出红果再打开。新安装默认关闭新外观；升级不会擅自改变用户已有的去广告开关。

原生玻璃需要系统提供 UIGlassEffect，且宿主启动时启用新的设计路径。即时开启时若启动条件未满足，会使用系统磨砂；重启后重新检查。既有进程参数并不是 Apple 对第三方注入插件的兼容承诺。

## 独立实现与兼容边界

产品行为参考 NaiwaGuo 0.1.1 的说明和宿主接口记录。Honggo 的新源码、设置模型、状态恢复、导航映射和测试均独立编写，没有导入 NaiwaGuo 源码文件、代码片段、字体、图片、赞赏或社群素材。相同的宿主类与 selector 是适配所需接口名称，不代表引用对方实现。

本版仍限定 Eggplant 7.4.3.33 / 红果 7.4.3。未获得新的原始 IPA，新增视图适配采用已有接口记录并在运行时检查类、方法签名与视图关系。参考项目的适配说明不能替代目标版本的真实设备验证。

为保护宿主使用，以下限制是本版的明确边界：

- 宿主底栏无法完整映射原始 UIControl 事件，或可用空间不足以保留 44 点点击区域时，保留原导航。配置尺寸受宿主空间限制，不强行拉伸整个根视图。
- 本版底栏使用系统 SF Symbols，不读取用户头像，也没有修改宿主标签的业务含义。
- 作者、标题与描述在「作者与剧集信息」中按已确认的容器整体调整，未按文本内容猜测拆分。未适配的其他控件保持原样。
- 竖屏填满判断依据已识别渲染视图几何，不是重新解码媒体；不宣称已经扩展所有宿主嵌套容器到整个屏幕。
- 面板只清理其内部已识别的普通大面积背景，不隐藏 DanceUI/Compose 绘制层或修改全局 UIKit/CALayer。部分自绘背景可能仍然不透明，需要真机现场确认。
- 字体作用于已适配播放页、面板和新底栏原生文字，不替换视频内字幕、网页或自绘文字；密码、编辑中的输入和图标字体保持原样。字体导入上限 50 MiB，图片输入上限 12 MiB，图标本地归一为不超过 256 像素的 PNG。
- 外观参数备份不打包字体或图片；跨设备恢复后须重新选择资源。原有功能备份仍只处理原来的 16 个开关，外观有独立导出入口。
- 状态报告表示接口安装情况，不表示功能在每个广告、面板或设备上都已验收。

## 工程组织

`AppearancePreferences.m`：严格类型、数值范围、字段白名单及原子配置写入。

`Appearance.m` 与四个 `.inc`：仅对已知宿主目标安装经过签名核对的 hook；材质、布局、图标、字体、底栏和原生设置。没有全局 UIView/UILabel 修改，没有播放状态修改，没有网络上传或广告奖励伪造。

插件拥有的视觉属性在关闭、复用或宿主改变时恢复；无法确定归属的值不强行覆盖。导航只转发已映射的原始控件事件；点赞和收藏不以点击次数推断状态。

## 验证

新增 Foundation 参数测试和真实 UIKit 下的受控宿主测试。构建使用 Xcode 的 iPhoneOS/Simulator SDK；编译失败、行为测试失败均阻止测试版发布。

真实红果 App 的切集、页面复用、横竖屏、面板背景、字体覆盖及 iOS 27.3 玻璃效果尚未真机验收。以 GitHub Actions 对应提交的实际结果和发布校验文件为准，不能将受控宿主测试写成真机效果。
