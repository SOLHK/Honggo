# Honggo 1.1.15-R6：外观功能与搜索转场修正

本版包含 R5 的八类独立外观实现，使用入口仍为「我的 → 设置 → Honggo → 左上角『外观』」。应用「玻璃外观」预设后完全退出重开；字体与竖屏填满需单独选择。默认不改变已有去广告开关。

## 修正

- 完整回归发现：原设置页在搜索呈现动画刚结束时立即点击“完成”，可能在 UIKit 尚未处理完搜索转场时尝试关闭父窗口，导致关闭请求未生效。设置页和新外观页均改为使用公开转场协调器完成回调，并在下一主队列轮次执行后续动作。不删去失败断言、不用固定延时掩盖问题。
- 评论玻璃补充已知的标题、列表、底部工具栏和编辑器容器，减少对控制器名称的依赖。没有全局修改 UIView、CALayer 或自绘渲染层。
- 主设置“关闭全部功能”关闭外观总开关，但保留用户的字号、图标、位置和颜色等参数。外观页面的“恢复全部默认值”仍执行明确的配置重置。
- 图标状态保存 UIImageView 实际保留的图像值，恢复时兼容 UIKit 对 SF Symbol 的归一处理；宿主后来更新的原图标可成为新恢复基线。

## 验证边界

新增外观参数测试与真实 UIKit 受控宿主测试，原设置搜索、广告、底栏、诊断等回归继续作为发布门槛。具体结果以本版本对应 GitHub Actions 和校验文件为准。

未在真实红果 iPhone 中运行；接口检查和模拟宿主测试不能证明所有真实页面都已生效。适配对象仍为红果 7.4.3 / Eggplant 7.4.3.33，arm64，最低编译目标 iOS 15.0.1。完整功能及明确限制见 [R5 外观实现说明](REPAIR_1.1.15-R5.md)。

外观参数备份不包含图标图片或字体文件。字体只作用于已适配原生文字；竖屏画面填满不拉伸横屏或方形视频；底栏保留可用点击空间，接口不匹配时回退原导航。
