# Honggo 1.1.15-R3 原生试玩卡拦截

2026-11-14 的日志确认 R2 在 Eggplant 7.4.3.33 安装了全部 45 条规则，13 条有命中。R2 的小游戏工厂及剧终开关均未记录命中。导出快照属于设置页，`maskScenes` 为空，因此截图与类的关联来自静态分析。R2 两条规则没有命中的原因尚未确定。[日志脱敏统计](reverse/7.4.3.33/r3/r2-log-summary.json)

截图的「点击进入游戏」可在宿主程序的 `SSShortVideoFeedDirectGameContentView bindContentModel:` 找到。绑定方法还使用游戏名、摘要和试玩入口图标。两个已核实调用方用同一个工厂创建原生试玩卡模型，普通混排和剧终插入分别传入 `source=1`、`source=2`。两个分支在 `0x10006198` 和 `0x10005ab8` 检查 `nil`，并在创建页面或准备插入前退出。文件偏移、原始指令和类型编码见 [REA 摘要](reverse/7.4.3.33/r3/r3-rea-summary.json) 与 [调用证据](reverse/7.4.3.33/r3/direct-gate-evidence.json)。

R3 在共同工厂返回 `nil`，并给原生试玩卡模型增加已入队处理。该处理先执行宿主的 `modelDidDisplay`，在下一次主队列调度时确认页面仍显示同一模型，再走 `handleTerminalFailureWithReason:`。宿主负责切换当前页、释放游戏资源与删除条目。当前页面已切换、绑定已变更、模型已失效或宿主类型未知时，会跳过移除。如果走已入队处理，屏幕上可能短暂出现试玩卡。

两条新增规则沿用「隐藏短剧广告、直播和小游戏插播」开关，安装后合计 47 条。回归覆盖两个工厂调用参数、手动游戏入口、两种宿主的延迟移除、重复显示以及页面切换后的状态确认。模拟器用受控宿主验证这些条件。红果真机的同一广告、切集与切换动画等待复测。

后续排查可复用 [完整索引](AD_AUDIT_7.4.3.33.md)。房间和试玩媒体内容来自运行时，档案保存原生程序的静态证据及脱敏统计。
