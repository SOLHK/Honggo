# Honggo 1.1.15-R9 — 全集跳转布局保护与灰色玻璃底栏

基线：`514a0914f849d323f7ecdb1ee4c332d138da01fc`（已发布 R8）。宿主：红果短剧 7.4.3 / Eggplant 7.4.3.33。继续使用 Xcode 27.2、iPhoneOS SDK 27.2 和固定 iOS 27.2 模拟器发布门槛。

## 反馈与证据

用户反馈：竖屏占满的视频点击「观看全集」卡住；底栏图标比例不协调，选中项目呈蓝色，希望采用参考图中的白色图标和半透明灰色选中背景。

上传日志的插件身份是 Honggo 1.1.15-R8，系统为 iOS 27.3。1,449 条事件覆盖四个进程会话，没有事件丢弃或容量裁剪。114 次播放观察入口都有成对进入和返回；77 次播放结束判断均返回不拦截。123 条贴片展示事件记录已转交原实现，但该事件不证明原实现完成，也不证明回调已经执行。

没有卡死堆栈、全集点击事件或播放帧进度；导出的三个现场都是个人页，且没有外观参数。因此，不能由“画面占满”推定 `player.fullscreen` 已开启，也不能据此断定某个广告回调造成卡死。脱敏证据见 [R9 日志统计](reverse/7.4.3.33/r9/log-triage.json)。原始诊断和用户截图不入库。

## 布局与播放器移交

源码中确认并修正了以下风险：

- 旧版在每次原生布局前恢复变换，随后又应用同一缩放；画面填满函数还会再次恢复。现在保存原生基线，从 `bounds`、`center` 和未修改的基线计算；目标未变时不再写入 transform。
- `TTPlayerView` 和播放画布改变父容器或窗口前，只恢复仍由插件持有的变换；新的宿主变换优先。移交过程中暂停缩放，布局稳定后重新计算。只在两个已识别类上添加公开 UIView 生命周期适配，并校验完整 ABI。
- 原生控制器存在转场协调器时暂停填满，每个协调器只注册一次完成回调，完成或取消后交给下一次布局更新。旧回调使用弱引用和父容器检查。
- 右侧玻璃曾每次先写满控件容器，再写回圆形。现在先计算最终圆形尺寸，仅在实际变化时写入。全集入口玻璃只插入一次，不再与宿主反复争抢子视图次序。
- 隐藏控件不再每次先显示、再隐藏。玻璃效果延迟到已附着窗口且几何有效时创建，脱离窗口时释放效果。

修复不替换全集的点击动作，不创建第二个播放器，也不主动调用播放、暂停或倍速控制。R8 的宿主回调转交方式和已有广告过滤规则继续保留。

## 底栏样式

- 半透明玻璃使用局部深色表面和白色 SF Symbols；“我的”采用简洁人形，统一线条和尺寸上限。
- 选中背景由独立、不可交互的灰色半透明圆角块绘制；宽度有上限，隐藏部分标签后也不会铺满半条底栏。
- 关闭按钮的自动选中配置，并明确前景和透明背景，避免系统再次染上蓝色。
- 图标、图文、纯文字、独立圆按钮、隐藏标签、收缩和原生导航转发均保留。明确设置过的图标颜色继续生效，纯色材质继续跟随宿主浅色/深色。

## 回归与交付边界

新增受控 UIKit 宿主检查：

1. 画面填满与全集入口玻璃的四种开关组合；点击命中原控件且原动作只执行一次。
2. 同窗口播放器移交、返回信息流、移出窗口和宿主新变换；稳定布局不再重复写入 transform。
3. 原生子视图顺序保留、圆形玻璃尺寸稳定、HUD 几何与点击区域保持。
4. 受控原生转场协调器的完成、取消和完成回调注册返回 NO 场景；连续布局只注册一次，完成后安排安全的布局更新。
5. 底栏选中及按压状态的实际渲染像素、灰色选中块大小、白色图标、颜色自定义、纯色模式与受控预览截图。

本地 Python 工具检查与旧 SDK 上的语法预检查不能替代 iOS 27.2 编译或 UIKit 执行。正式的构建结果以该提交关联的 Actions 为准；全部既有门槛通过后，工作流才发布设备 dylib、源码提交号和 SHA-256。模拟器使用受控宿主，没有运行真实红果 IPA，也未模拟解码和网络播放。

## 真机复测

替换旧插件，确认设置显示 R9；先保留原来的外观参数。重复测试「竖屏满屏信息流 → 观看全集 → 返回 → 换剧再次进入」，再测试画面填满和全集玻璃的不同开关组合，并回归清屏长按倍速后自动下一集。

观察底栏白色图标与灰色选中块、各标签及独立按钮是否正常。若之前主动填写过选中/未选中图标颜色，可清空该颜色字段以使用新的默认白色。

若仍卡住，增强诊断现在包含播放器容器移交和 `fullscreen`、`episodeGlass`、`rightGlass`、`dock` 标志。能够返回设置时导出；无法返回时反馈是否仍有声音、进度是否变化、能否手势返回，以及是否必须强制关闭应用。不能把当前日志分析或受控测试写成这台 iPhone 已通过验收。
